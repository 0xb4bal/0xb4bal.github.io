Why build these

Two reasons. First, the boring one: the enrichment, correlation and write-up steps that eat an analyst's shift are exactly the steps an agent should be doing, and the only way to know where that breaks is to build it and run it. Second, the useful one: an agent that produces a structured, evidence-labelled report from a lab target is a fast, cheap way to test whether my own triage logic is consistent when nobody is watching.

More on the detection side as rules get written — see notes.
