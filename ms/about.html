PENGANALISIS DI SEBALIK ALERT

Tentang saya

Saya seorang Security Operations Analyst dengan hampir empat tahun pengalaman menyiasat alert keselamatan dalam persekitaran SOC. Kerja saya merangkumi pemantauan dan siasatan alert melalui Microsoft Sentinel, Splunk, IBM QRadar dan LogRhythm, serta pengesahan ancaman menggunakan EDR dan platform threat intelligence.

Saya menumpukan pada perkara yang membantu mencegah pencerobohan: triage yang teliti, escalation pantas dan pemahaman tentang sebab sesuatu alert dicetuskan — bukan sekadar menutup ticket.

Di luar tugasan alert harian, saya membangunkan alatan peribadi untuk IOC enrichment menggunakan Python dan pemantauan browser menggunakan JavaScript. Saya mengukuhkan semula asas offensive security di platform latihan yang dibenarkan sambil meneroka security workflows berbantukan AI.

Kaedah siasatan

Proses saya ialah memahami konteks alert, memeriksa parsed fields dan raw events, mencari aktiviti terdahulu, melakukan pivot pada entiti berkaitan, menjalankan IOC enrichment, mengesahkan hasil security controls yang diperhatikan dan mendokumentasikan penilaian berasas. Skor reputasi IOC semata-mata bukan bukti compromise.

Pengalaman saya merangkumi QRadar AQL, case handling dalam Cortex XSOAR, historical IOC search, MITRE ATT&CK mapping dan incident reporting. Saya tidak mendakwa mempunyai pengalaman mengetuai threat hunting secara rasmi, detection engineering dalam production atau penetration testing profesional.

Cara saya bekerja

  • Labelkan semuanya. Fakta, pemerhatian, penilaian, andaian. Amalan ini mengelakkan semakan reputasi daripada terus dianggap sebagai keputusan muktamad.
  • Reputasi bukan bukti. IP dengan sejarah buruk wajar disemak, tetapi belum cukup untuk membuat kesimpulan.
  • Catatkannya. Runbook yang tidak diikuti lebih buruk daripada tiada panduan; detection rule tanpa catatan false positive boleh menyebabkan gangguan pada masa hadapan.
  • Automasikan tugasan berulang, kekalkan pertimbangan manusia.

Skop penerbitan

Nota awam ialah hasil kerja makmal peribadi atau kaedah umum yang dibina semula secara bebas. Data insiden, telemetry, playbook dan rekod siasatan milik majikan serta pelanggan tidak disertakan.
